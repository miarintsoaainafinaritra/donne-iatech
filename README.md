# Dashboard Qualité de l'Air - IA1

Dashboard interactif d'analyse de la qualité de l'air (AQI) à Madagascar.

## Prérequis

- Python 3.12.3
- Git

## Installation
pip install ipykernel

python -m venv venv
## Structure


# Linux/macOS
source venv/bin/activate

# Windows
venv\Scripts\activate

pip install -r requirements.txt
```

## Lancer le projet

Dashboard :

```bash
streamlit run dashboard.py
```

Notebook :

```bash
jupyter notebook notebook/analysis.ipynb
```
